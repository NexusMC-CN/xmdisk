# 04 · 接口定义

## 监听面（端口先分，鉴权后补）

| 平面 | 默认端口 | 内容 | 鉴权（后补） |
|---|---|---|---|
| 数据面 HTTP | :9000 | S3（根路径，path-style；**桶增删 405，桶生命周期归 admin，99-D025**）+ WebDAV（/dav/<bucket>） | SigV4 / basic |
| 数据面 SSH | :9001 | SFTP | SSH（密码=AK/SK；公钥后补） |
| 管理面 | :9002 | admin API + WebUI + Prometheus + health | admin token（必填，99-D023）+ 会话 token |
| 复制面 | :9003 | repl API | repl token（为空则不监听，99-D023③） |
| 公共读面 | :9004 | 只读文件分发：`GET/HEAD /<bucket>/<key>`（99-D024） | 无鉴权，仅认桶公共标志 |

admin/repl 凭证必填（"空 token = 不鉴权"已废除，仅存于包内单测直连形态）。路由组织：main.go 挂路由组，路由组挂鉴权 + 业务。

## Store 接口（协议适配层唯一入口）

```go
type Store interface {
    // 对象
    Put(ctx, bucket, key string, src io.Reader, opts PutOpts) (ObjInfo, error)
    Get(ctx, bucket, key string, rng *Range) (io.ReadCloser, ObjInfo, error)
    Stat(ctx, bucket, key string) (ObjInfo, error)
    Delete(ctx, bucket, key string) error
    Move(ctx, bucket, src, dst string) error
    SetAttrs(ctx, bucket, key string, patch AttrPatch) error
    List(ctx, bucket, prefix, delim, after string, max int) (ListResult, error) // max=0 合法（空列表+IsTruncated）

    // 目录（SFTP/WebDAV 用，S3 不感知）
    Mkdir(ctx, bucket, path string) error
    Rmdir(ctx, bucket, path string) error

    // 桶（桶生命周期收归 admin 面，99-D025：建桶即发钥、删桶级联删钥；
    // S3 数据面对桶增删一律 405）
    CreateBucket(ctx, name string, quota *int64, public bool) (*Cred, error) // AK/SK 服务端生成，Secret 仅此一次
    DeleteBucket(ctx, name string) error // 空桶 + 无在途 multipart；同事务删除绑定凭据
    SetQuota(ctx, name string, quota *int64) error
    BucketStat(ctx, name string) (BucketStat, error) // 含 used/quota/pending/object_count/public/access_key/secret_ok
    RotateBucketCred(ctx, name string) (*Cred, error) // 保 AK 换 SK；无钥桶自愈

    // multipart：本地会话表，不进 oplog，Complete 才产生 entry_put
    MpBegin / MpPut / MpComplete / MpAbort / MpList

    // 凭据查询（鉴权中间件用：验签后查 AK→桶 映射）
    LookupCred(ctx, accessKey string) (Cred, error)
}
```

四条设计原则：

1. **长上传不持锁**：流式落盘（无锁、完全并行，可能耗时几分钟）→ 毫秒级事务（条目 + 计数器 + oplog）→ ack。SQLite 写锁只在最后一下，10GB 与 1KB 上传占锁时间相同。
2. **写入路径固定顺序**：先内容后元数据。任意时刻崩溃只留下无主 blob（GC 收），永远不留指向虚空的元数据。
3. **协议语义在适配层翻译**：S3 的 delimiter/common-prefix、SFTP 的 mode 位、WebDAV 死属性到门口为止，核心不知道协议存在。List 一个方法同时服务 S3 ListV2 与树形列目录（delim="/"）。
4. **配额在 Store 内（同事务要求），鉴权在适配层（协议相关）**，中间件只拿 LookupCred。

## oplog 表

| 字段 | 类型 | 说明 |
|---|---|---|
| seq | uint64 | 单调递增，串行写下 max+1；顺序的唯一权威 |
| epoch | uint32 | fencing，promote 时 +1，从节点拒收低 epoch |
| ts | int64 | 仅调试与保留期计算，不参与排序 |
| type | enum | bucket_create / bucket_delete / quota_update / entry_put / entry_delete / tree_move / cred_put / cred_delete |
| payload | JSON | **全量状态**（非增量），幂等回放 |

要点：entry_put 携带完整条目（PUT / 覆盖 / SetAttrs / multipart Complete 全部收敛于此，改属性不重写内容）；tree_move 单 op（从节点本地一个事务重写前缀下全部 key，防大目录 rename 打爆日志）；multipart 会话与在途 blob 不进 oplog。

## admin API（:9002）

鉴权（99-D023⑤，双 token）：`X-Xm-Token`（admin token，env/YAML 必填）或 `X-Xm-Session`（短时会话）；除签发/全清外全部接口双轨接受，比较常数时间。内嵌管理页（WebUI）从本端口同源下发，登录页免凭证可见（静态资源无秘密）。

- 会话：`POST /auth/session {ttl_hours: 1-24}`（仅 admin token，换短时会话）、`DELETE /auth/session`（会话自吊销=登出）、`DELETE /auth/sessions`（仅 admin token，吊销全部）
- 状态：`GET /status`（role/serve/epoch/seq/sync、configured_role 与 role_mismatch 软提醒、repl token/监听状态、public_endpoint）、`GET /health`（含 sealed_secrets/sealed_secrets_unreadable——KEK 更换后定位待轮换桶）、`GET /metrics`（Prometheus：xm_node_* / xm_oplog_last_seq + first_seq / xm_slave_{acked,lag,active} / xm_bucket_*）
- 服务开关：`POST /serve {mode: off|ro|rw}`、`POST /sync {action: start|stop, master_addr}`（start 的地址持久化进运行态，重启自动恢复不回落旧配置）
- 故障切换：`POST /promote`（前置校验：role=slave、sync 已停；执行：epoch+1、接管复制面、serve 置 ro）
- 桶（99-D025：桶=租户=一把钥匙，凭据随桶生灭）：`GET /buckets`（含每桶 access_key 与 secret_ok，无 secret）、`POST /buckets {name, quota?, public?}`（**建桶即发钥**：响应一次性返回 access_key+secret）、`DELETE /buckets/{name}`（空桶+无在途 multipart，**级联删除绑定凭据**）、`PATCH /buckets/{name}`（字段存在性语义：缺席=不动、quota 显式 null=解除、public 布尔）、`POST /buckets/{name}/rotate`（重置该桶 Secret：保 AK 换 SK 一次性返回；无钥桶自愈补发；"冻结租户"=rotate 到不外发的新值）。**独立的 POST/DELETE /creds 接口已移除**（S-01 收口）
- 集群配置（99-D023③）：`POST /repl/token {token}`（运行时设置，KEK 封装存 node-state.json，master 热替换并联动监听起停）、`DELETE /repl/token`（清除，回落 env/YAML 初值）
- 运维：`POST /snapshot`（强制快照）、`POST /gc`（标记-清扫 + **联动 oplog 截断**一轮，响应含 TruncatedOps；截断策略=全部活跃从已 ack 且过保留期，**最新一条 op 永远保留作 seq 水位线**——2026-10-23 集群实测 P1 修复）、`POST /verify {limit}`（抽样哈希校验）
- 从节点观察（仅主节点开放，runbook A4/B2 验证入口）：`GET /slaves`（slaves 数组：ID/LastAcked/Lag/Epoch/LastSeenNs/Active；Active=false 为活跃窗口外的僵尸注册，不计门控）
- 灾备辅助：rescue 只读模式与指定前缀导出接口（**规划中，未实现**；当前旧主处置按 docs/03 runbook 人工执行）
- 变更类接口带审计日志（方法/路径/来源/结果码；凭据族只记 AK 永不记 SK，S-20）

## 公共读面（:9004，99-D024）

独立只读端口（`listeners.public`，默认 0.0.0.0:9004），无鉴权无签名，只认 `GET/HEAD /<bucket>/<key>`：桶 `public=true` 且对象存在 → 返回文件（ETag/Last-Modified/Content-Type，Range 206，If-None-Match/If-Modified-Since 304）；**桶未开公共/桶不存在/对象不存在/目录 → 同构 404**（防枚举）；其他方法 405。**不发任何缓存头**（缓存策略归用户反代层，99-D024）；走 serveGate（serve=off 503、ro 照常）。S3/WebDAV/SFTP 面永远要求凭据——公共读只在此端口生效。

## 错误语义映射

Store 层定义唯一的内部错误枚举（sentinel error），三个协议适配层各自维护一张**穷举**映射表；用 map + 启动期完整性检查实现（无 default 分支，新增错误漏配某一协议时进程拒绝启动）。

| 内部错误 | S3 | SFTP | WebDAV |
|---|---|---|---|
| BucketNotFound | 404 NoSuchBucket | —（桶→根在挂载配置层解析） | 404 |
| KeyNotFound | 404 NoSuchKey | SSH_FX_NO_SUCH_FILE | 404 |
| UploadNotFound | 404 NoSuchUpload | — | — |
| BucketExists | 409 BucketAlreadyExists | — | 405 |
| IsDirectory | GET 无尾斜杠按 KeyNotFound；GET `foo/` 返回目录标记；**DELETE `foo/` 走目录标记删除**（204：仅删标记条目，子条目不动，非空目录仍以前缀呈现——标准 S3 语义） | SSH_FX_FAILURE + "is a directory" | PUT 到集合路径 409；列目录用 PROPFIND |
| IsFile | — | SSH_FX_FAILURE + "not a directory" | 409 |
| DirNotEmpty | 409 BucketNotEmpty（删非空桶） | SSH_FX_FAILURE + "directory not empty" | 409 |
| QuotaExceeded | **507** QuotaExceeded（文档化偏离） | SSH_FX_FAILURE + 消息 | 507（原生语义） |
| ReadOnly | 503 + ReadOnly（可重试） | SSH_FX_FAILURE + "read-only" | 503 |
| EntityTooLarge | 400 EntityTooLarge | SSH_FX_FAILURE | 413 |
| RangeInvalid | 416 InvalidRange | 越界读返回 EOF（POSIX 语义） | 416 |
| PreconditionFailed | 412 PreconditionFailed | —（SFTP 无条件语义） | 412 |
| NotModified | 304 | — | 304 |
| PermissionDenied | 403 AccessDenied | SSH_FX_PERMISSION_DENIED | 403 |
| InvalidArgument | 400 InvalidArgument | SSH_FX_BAD_MESSAGE | 400 |
| Internal | 500 InternalError | SSH_FX_FAILURE | 500 |

三条原则（99-D017）：

1. S3 错误响应用标准 XML（Code/Message/Resource/RequestId）——SDK 按 Code 区分，不靠 HTTP 码或文案。
2. QuotaExceeded 取 507 而非 403：403 会被部分 SDK/工具当凭证问题（换 key 重试、误报警），507 语义准确，业务平台按 Code 处理。
3. SFTP v3 没有细分错误码（无 quota/只读码），统一 SSH_FX_FAILURE + 可读消息。
