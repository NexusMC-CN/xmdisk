# 06 · 测试清单

目的：回答"测了什么、为什么测、失效会有什么后果"，并如实列出**尚未覆盖的缺口**——
供审阅：发现没考虑到的风险，就是本文档最大的价值。

维护规则：每个里程碑合入前更新本文档；缺口关闭时移入对应模块表并注明关闭方式。

## 风险分级

- **数据安全**：失效直接丢数据或数据损坏（最高优先，防御最多、测试最多）
- **一致性**：失效导致主从不一致、计费错误、状态漂移
- **可用性**：失效导致拒绝服务、性能塌陷
- **安全**：失效导致越权访问

## blob 数据面（internal/blob）

| 用例 | 验证 | 为什么 | 失效后果 | 级别 |
|---|---|---|---|---|
| Put/Open/Size 往返 + sha256 对账 | 写入即哈希，读回一致 | 哈希是内容寻址的根基 | 引用错乱、静默损坏 | 数据安全 |
| 同内容重复 Put 去重 | 目标已存在时复用而非重写 | 去重是设计承诺 | 空间浪费、竞态写坏 | 一致性 |
| 非法哈希拒绝（路径穿越） | `../etc/passwd`、短哈希被拒 | 哈希拼路径，防目录逃逸 | 任意文件读写 | 安全 |
| Trash → 宽限期内不清扫 | mtime 即标记时间戳 | 两阶段 GC 的标记语义 | 提前回收 | 数据安全 |
| 清扫 keep=true 复活 / 已存在时清副本 | 重验存活、复活冲突处理 | 自愈承诺（不信标记） | 误删活数据 / Windows rename 崩溃 | 数据安全 |
| 空内容 blob | 0 字节对象可写可读 | 空文件是合法输入 | 空对象丢失 | 可用性 |
| **符号链接跳板全路径**（99-D018） | 链接占位时 Exists/Open/Size 拒绝、List 过滤、同内容重写铲除自愈、trash 链接只删不复活且目标不被触碰 | 备份还原项目真实事故：存储目录内的链接可读写外部文件 | **越出存储目录读任意文件** | 安全 |
| **流式配额守卫**（99-D019，store 表见下） | 32MB 流灌 1MB 配额桶：额度+缓冲内早中断、磁盘零残留、计数不动、覆盖写抵扣正确 | 流式特大文件可在被拒前写满磁盘（磁盘全局共享） | 单客户端打爆 16TB 池、殃及其他桶 | 数据安全 |

## 已知缺口（按风险排序，审阅重点）

1. **`-race` 竞态检测未跑**：本机无 CGO。并发面目前小（一个 atomic + SQLite 串行写），
   但 S3 层并发请求路径未做数据竞争验证。→ 计划：Docker 起 golang 容器跑 `CGO_ENABLED=1 go test -race`。
2. **真实客户端兼容性未端到端验证**：SigV4 的测试用例由测试侧签名器生成——它与被测代码
   **共享 canonicalRequest 实现**（同源风险：若规范理解有误，两边一起错，测试仍绿）。
   → 计划：Docker 阶段用 aws-cli / rclone 真实客户端冒烟（put/get/ls/mp/presign）。
3. **崩溃一致性未在 Linux 验证**：blob fsync + SQLite FULL 的断电语义在 Windows 测试机上
   不可靠复现。→ 计划：Linux 容器/测试服务器做 kill -9 循环 + 断电模拟（如可能）。
4. **GB 级大文件未测**：单测时间约束，最大只到 5MB 两块。分块数学理论上无上限差异，
   但 16TB 目标规模建议后续做一次 10GB 级手工验证。→ 计划：测试服务器。
5. **并发压测未做**：高并发 PUT/GET/List 的吞吐与锁行为无数据。→ 性能非本轮目标，记账正确性由串行测试覆盖，并发正确性依赖缺口 1。
6. **主从多进程端到端未做**：当前集成测试是进程内 httptest；真实端口、跨进程、重启恢复未演练。→ 计划：Docker compose 1 主 2 从 + 故障注入（含灾备 runbook A0-A6 自动化回归）。
7. **admin/promote 未实现**：灾备 runbook 无法端到端演练（serve/sync/promote 是下一里程碑）。
8. **presign 仅测了 GET**：PUT presign 实现支持但无用例。→ 小缺口，下轮补。
9. **符号链接测试在 Windows 开发机跳过**（无创建链接权限，测试内自动 skip 并提示）：Lstat 加固已按 Linux 语义编写，容器阶段自动真跑。
10. **快照期间并发写入的一致性**：VACUUM INTO 读事务理论上不阻塞写，未直接验证快照内容与截断点吻合（bootstrap 测试间接覆盖了正确路径）。
11. **网络分区/半连接**：未模拟（分区误判属灾备流程风险，靠 A0 人工确认兜底）。

## 测试方式说明

- 全部用例：`go test ./... -count=1`，gofmt/vet 干净；
- 每个包独立临时目录（t.TempDir），无跨用例共享状态；
- repl/s3 用真实 HTTP（httptest）走完整协议栈，不 mock。
